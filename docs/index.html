Chess Problem Helper

Set up a position, solve it, and read the play the way a problem magazine prints it: set play, tries with their refutations, the key, and what changes between them.

Pick a piece, then click squares to place it. The eraser clears a square.

Press Solve to analyse the position.
Runs entirely in your browser. The same analysis is available offline as the Python package in this repository: python -m chesscomp.report --fen "…" "#2" --critique.
